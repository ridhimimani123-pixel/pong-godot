
# Pong

Classic Pong with 3 AI difficulty levels (Easy, Medium, Extreme), built in Godot 4 with GDScript. Beat the AI to 5 points.

Play it: https://ridhi-mimani.itch.io/pong

## Features
- 3 difficulty levels with different AI paddle speeds
- Pause, restart and return-to-menu controls
- Score tracking and game over screen
- Sound effects for hits and scoring

## Controls
- Up / Down arrows: move paddle
- Esc: pause
- R: restart
- M: back to menu
- Enter: play again after game over

## Run from source
1. Install Godot 4
2. Open the project folder in Godot
3. Press F5

## Built with
- Godot 4 (GDScript)
